## 📖 Опис проєкту

**LOST** — це пригодницька 2D-гра у жанрі pixel art, в якій гравець керує персонажем у тропічних джунглях. Ключовою особливістю проєкту є **повна інтеграція з реляційною базою даних H2**: авторизація користувачів, збереження ігрового прогресу, інвентар, таблиця лідерів та кооперативні сесії — все зберігається у БД у реальному часі.

Проєкт розроблено як навчально-практичну роботу з метою демонстрації застосування патернів проєктування, нормалізації баз даних та принципів чистої архітектури у реальному застосунку.

---

## ✨ Функціональність

- 🔐 **Аутентифікація** — реєстрація та вхід з хешуванням паролів (BCrypt)
- 💾 **Збереження прогресу** — збереження/завантаження координат та інвентарю через SQL
- 🎒 **Інвентар** — автоматична фіксація предметів у таблиці `inventory_items`
- 🏆 **Таблиця лідерів** — рейтинг гравців за набраними очками
- 🤝 **Кооперативний режим** — підключення до спільної сесії за кодом кімнати
- 💬 **Діалоги з NPC** — текст діалогів зберігається у таблиці `dialogue_lines`
- ⚙️ **Налаштування** — гучність та режим відображення

## 🏗️ Архітектура

Проєкт побудований за **чотирирівневою архітектурою**:

```
┌─────────────────────────────────┐
│  Presentation Layer (JavaFX)    │  ← controller/
├─────────────────────────────────┤
│  Business Logic Layer           │  ← service/
├─────────────────────────────────┤
│  Data Access Layer (DAO/JDBC)   │  ← dao/
├─────────────────────────────────┤
│  Database Layer (H2 + Flyway)   │  ← db/migration/
└─────────────────────────────────┘
```

### Використані патерни
- **DAO** (Data Access Object) — ізоляція SQL-запитів
- **Singleton** — єдиний екземпляр ConnectionPool
- **Facade** — спрощений інтерфейс сервісного рівня
- **Connection Pool** — ефективне управління з'єднаннями з БД

## 🚀 Встановлення та запуск

### Варіант 1: Готовий інсталятор (рекомендовано)

1. Перейдіть на сторінку релізів: [GitHub Releases](https://github.com/Izumi255/lost-database/releases/latest)
2. Завантажте файл `LOST-X.X.X.msi` (для Windows 10/11)
3. Запустіть інсталятор та дотримуйтесь інструкцій
4. База даних ініціалізується **автоматично** при першому запуску

### Варіант 2: Збірка з вихідного коду

**Вимоги:**
- Java JDK 21+
- Maven 3.9+

**Команди:**
```bash
# Клонувати репозиторій
git clone https://github.com/Izumi255/lost-database.git
cd lost-database

# Зібрати та запустити
mvn clean javafx:run
```

## 🗄️ Схема бази даних

База даних містить **9 таблиць**:

```
players          — облікові записи користувачів
game_saves       — збережені стани гри
inventory_items  — предмети інвентарю
game_sessions    — кооперативні сесії
session_players  — учасники сесії (M:N)
leaderboard      — таблиця лідерів
dialogue_lines   — діалоги NPC
player_achievements — досягнення гравців
settings         — налаштування програми
```

Міграції схеми виконуються автоматично через **Flyway** при кожному запуску.

## 📁 Структура проєкту

```
lost-database/
├── src/
│   ├── main/
│   │   ├── java/com/lost/database/
│   │   │   ├── app/          # Точка входу (Launcher, LostDatabaseApp)

│   │   └── resources/

│   │       └── assets/       # Ресурси гри (спрайти, звуки)

```
